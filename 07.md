# 07 — RNNs & Sequential Data

## 50. Why are ordinary neural networks not ideal for sequential data?
Standard feed-forward networks do not naturally maintain information from previous time steps and usually treat fixed inputs independently. Sequential data depends on order and context, such as text, speech, time series, and sensor data.

## 51. What is an RNN?
RNN stands for Recurrent Neural Network. It processes a sequence one step at a time while maintaining a hidden state that carries information from previous steps.

**hₜ = f(Wₓxₜ + Wₕhₜ₋₁ + b)**

## 52. How does an RNN process sequential data?
At each time step it receives the current input and previous hidden state, computes a new hidden state, optionally produces an output, and passes the hidden state to the next time step.

## 53. What is the vanishing gradient problem in RNNs?
During backpropagation through many time steps, gradients can repeatedly become smaller. Early time steps then receive very weak learning signals, making long-term dependencies difficult for basic RNNs.

## 54. What is an LSTM?
LSTM stands for Long Short-Term Memory. It is a gated RNN architecture designed to preserve information over longer sequences using forget, input, and output gates plus a cell state.

## 55. What is a GRU?
GRU stands for Gated Recurrent Unit. It is a gated recurrent architecture using update and reset gates. It is generally simpler and has fewer parameters than an LSTM.

## 56. LSTM vs GRU — what is the difference?
| LSTM | GRU |
|---|---|
| Cell state + hidden state | Combined hidden representation |
| Forget, input, output gates | Update and reset gates |
| More parameters | Fewer parameters |
| More complex | Simpler |

Neither is universally better; the choice depends on task and resources.
