# 05 — Neural Network Training & Regularization

## 31. What is an epoch, batch, and iteration?
**Epoch:** one complete pass through the training set. **Batch:** a subset processed together. **Iteration:** one parameter update, usually after one batch. If 10,000 samples are divided into batches of 100, one epoch has about 100 iterations.

## 32. What is overfitting in neural networks?
Overfitting occurs when a model learns training data too specifically and performs worse on unseen data. A common sign is training performance improving while validation performance stops improving or gets worse.

## 33. What is dropout?
Dropout randomly sets a fraction of activations to zero during training. It is a regularization technique that reduces dependence on particular neurons.

## 34. How does dropout reduce overfitting?
By randomly removing activations during training, dropout discourages the network from relying too heavily on particular pathways and encourages more distributed representations.

## 35. What is Batch Normalization?
Batch Normalization normalizes intermediate activations using mini-batch statistics during training, followed by learnable scale and shift parameters. It can stabilize and speed up optimization. During inference, running estimates are generally used.

## 36. Batch Normalization vs Layer Normalization?
**BatchNorm:** normalizes using statistics across the batch for each feature/channel and is common in CNNs. **LayerNorm:** normalizes across features within each individual sample and is common in Transformers. LayerNorm does not depend on batch statistics in the same way.

## 37. What is early stopping?
Early stopping ends training when validation performance stops improving for a chosen patience period. It saves computation and can reduce overfitting.

## 38. What is weight decay?
Weight decay discourages excessively large weights. A common objective can be written as **Total Loss = Data Loss + λ × Regularization Term**. Decoupled weight decay is also implemented separately in some optimizers.

## 39. How do you diagnose underfitting and overfitting during training?
**Underfitting:** training and validation performance are both poor → consider more capacity, better data/features, longer training, or less regularization. **Overfitting:** training performance is strong but validation performance is much worse → consider augmentation, dropout, weight decay, early stopping, more data, or a smaller model.

## 40. What techniques can improve neural network generalization?
More representative data, augmentation, dropout, weight decay, early stopping, appropriate model size, suitable normalization, transfer learning, and careful hyperparameter tuning can improve generalization.
