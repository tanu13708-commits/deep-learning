# Deep Learning

Deep Learning is a subfield of Machine Learning that uses neural networks with multiple layers to learn useful representations directly from data.

## Main Areas

1. Deep Learning Fundamentals
2. Activation Functions
3. Backpropagation & Optimization
4. Loss Functions
5. Training & Regularization
6. CNNs & Computer Vision
7. RNNs & Sequential Data
8. Attention & Transformers
9. Transfer Learning & Fine-Tuning
10. Practical Deep Learning & Debugging

## Core Learning Flow

```text
Data → Input Layer → Hidden Layers → Activation → Forward Pass
→ Prediction → Loss → Backpropagation → Gradients → Optimizer
→ Updated Weights → Repeat
```
