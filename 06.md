# 06 — CNNs & Computer Vision

## 41. What is a Convolutional Neural Network?
A CNN is a neural-network architecture designed for spatially structured data such as images. It uses convolutional filters to learn local patterns such as edges, textures, shapes, and higher-level visual features.

## 42. What is convolution?
Convolution applies a small kernel across an input and computes local weighted combinations, producing a feature map. In deep-learning libraries the operation is technically often cross-correlation, but it is commonly called convolution.

## 43. What are kernels/filters?
A kernel is a small matrix of learnable weights that scans across the input. Different filters can learn different patterns such as edges, textures, or more complex structures.

## 44. What are stride and padding?
**Stride** is how far the filter moves at each step. Larger stride usually reduces spatial dimensions faster. **Padding** adds values around the input, often zeros, and can help preserve dimensions and edge information.

## 45. What is a feature map?
A feature map is the output produced by applying a learned filter to an input. It indicates where the learned pattern is strongly activated. A layer typically produces multiple feature maps.

## 46. What is pooling and why is it used?
Pooling reduces spatial dimensions and summarizes local information. Max pooling and average pooling are common. Pooling reduces computation and spatial size and can provide some translation tolerance. Some modern CNNs instead use strided convolutions.

## 47. Why are CNNs effective for images?
CNNs exploit spatial structure through local connectivity and shared weights. The same filter can detect a pattern at different image locations, while deeper layers learn increasingly complex features.

## 48. What is the difference between convolution and fully connected layers?
Convolution layers use local connections and shared filter weights while preserving spatial structure. Fully connected layers connect every output unit to every input unit and do not naturally preserve spatial locality.

## 49. What are transfer learning and pretrained CNNs?
Transfer learning uses a model trained on a large dataset as a starting point for a related task. A pretrained CNN can be used as a fixed feature extractor or fine-tuned on the target dataset.
