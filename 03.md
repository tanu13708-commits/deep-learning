# 03 — Backpropagation & Optimization

## 15. What is backpropagation?
Backpropagation efficiently computes gradients of the loss with respect to neural-network parameters by applying the chain rule from the output layer backward. An optimizer then uses these gradients to update parameters.

## 16. Explain the chain rule in the context of neural networks.
If **y=f(g(x))**, then **dy/dx=(dy/dg)(dg/dx)**. Neural networks contain many nested operations, so backpropagation repeatedly applies the chain rule to find how each parameter affects the loss.

## 17. How are gradients calculated?
Gradients are derivatives of the loss with respect to parameters: **∂L/∂θ**. Backpropagation computes them efficiently from later layers toward earlier layers.

## 18. What is gradient descent?
Gradient descent updates parameters in the direction that reduces loss:

**θ_new = θ_old − η∇L(θ)**

where η is the learning rate.

## 19. Batch vs mini-batch vs stochastic gradient descent?
- **Batch:** uses the full training set for one update.
- **Stochastic:** uses one example per update.
- **Mini-batch:** uses a small subset per update and is most common in practical deep learning.

## 20. What is the learning rate?
The learning rate controls the size of each parameter update. It strongly affects training speed and stability.

## 21. What happens when the learning rate is too high or too low?
**Too high:** updates may overshoot, oscillate, or diverge. **Too low:** training becomes very slow and may appear stuck.

## 22. What are vanishing and exploding gradients?
**Vanishing gradients:** gradients become extremely small as they move backward, so early layers learn slowly. **Exploding gradients:** gradients become very large, causing unstable updates. They can occur in very deep or recurrent networks.

## 23. What is gradient clipping?
Gradient clipping limits gradient magnitude, often by clipping its norm, to reduce instability from exploding gradients.

## 24. What are optimizers such as SGD, Momentum, RMSProp, and Adam?
- **SGD:** basic gradient-based updates.
- **Momentum:** uses accumulated gradient direction to reduce oscillation and accelerate progress.
- **RMSProp:** adapts update scaling using a moving average of squared gradients.
- **Adam:** combines first- and second-moment tracking for adaptive updates and is widely used in practice.
