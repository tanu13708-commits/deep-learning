# 04 — Loss Functions

## 25. What is a loss function?
A loss function quantifies the difference between predictions and targets. Its value and gradients guide parameter updates during training.

## 26. MSE vs MAE for regression?
**MSE = (1/n)Σ(y−ŷ)²**. It penalizes large errors strongly. **MAE = (1/n)Σ|y−ŷ|**. It is less sensitive to large outliers. MSE is smooth and common; MAE is more robust to extreme errors.

## 27. What is Binary Cross-Entropy?
For target y and predicted probability p:

**L = −[y log(p) + (1−y)log(1−p)]**

It is commonly used for binary classification and penalizes confident incorrect predictions strongly.

## 28. What is Categorical Cross-Entropy?
For one-hot target y and predicted probabilities p:

**L = −Σ yᵢ log(pᵢ)**

It is commonly used for multi-class single-label classification.

## 29. Why is cross-entropy commonly used for classification?
It compares predicted and target probability distributions and strongly penalizes assigning low probability to the correct class. With common sigmoid/softmax outputs it also has convenient gradients for optimization.

## 30. How would you choose an appropriate loss function?
Consider the problem type, target representation, output layer, error characteristics, outliers, and evaluation objective. Examples: regression → MSE/MAE/Huber; binary classification → BCE; multi-class → categorical cross-entropy; multi-label → BCE per label.
