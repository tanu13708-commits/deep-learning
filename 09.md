# 09 — Transfer Learning & Fine-Tuning

## 66. What is transfer learning?
Transfer learning uses knowledge learned from one task or dataset as a starting point for another related task. For example, a CNN pretrained on a large image dataset can be adapted to classify plant diseases.

## 67. Feature extraction vs fine-tuning?
**Feature extraction:** freeze the pretrained backbone and train a new task-specific head. **Fine-tuning:** unfreeze some or all pretrained layers and continue training, usually with a smaller learning rate.

## 68. When should you freeze layers?
Freezing is useful when the target dataset is small, pretrained features are relevant, faster training is desired, or you want fewer trainable parameters. Layers can be gradually unfrozen if more adaptation is needed.

## 69. What is catastrophic forgetting at a high level?
Catastrophic forgetting occurs when learning a new task causes a model to lose useful knowledge from a previous task. Aggressive fine-tuning on small or very different data can increase this risk.

## 70. How would you fine-tune a pretrained deep learning model?
1. Choose a relevant pretrained model.
2. Replace/modify its output head.
3. Initially freeze much of the backbone if appropriate.
4. Train the new head.
5. Optionally unfreeze selected layers.
6. Use a smaller learning rate for pretrained layers.
7. Monitor validation performance.
8. Use regularization/early stopping where appropriate.
9. Evaluate on an untouched test set.
