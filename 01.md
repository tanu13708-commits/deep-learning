# 01 — Deep Learning Fundamentals

## 1. What is Deep Learning and how is it different from traditional Machine Learning?
Deep Learning is a branch of Machine Learning that uses neural networks with multiple layers to learn representations from data. Traditional ML often depends more heavily on manually designed features. For images, traditional ML may require hand-crafted features, while a CNN can learn useful features directly from pixels. Deep Learning often benefits from large datasets and significant computational resources.

## 2. What is an artificial neuron?
An artificial neuron takes inputs, multiplies them by weights, adds a bias, and applies an activation function.

**z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b**

**output = f(z)**

## 3. What is a neural network?
A neural network is a collection of interconnected artificial neurons organized into layers. It learns a mapping from inputs to outputs by adjusting weights and biases during training.

## 4. What are input, hidden, and output layers?
- **Input layer:** receives input features.
- **Hidden layers:** transform information through weighted operations and activations.
- **Output layer:** produces the final prediction.

## 5. What are weights and biases?
Weights determine how strongly inputs contribute to a neuron. Bias shifts the weighted sum. A neuron computes **z = wx + b**. Both are learned during training.

## 6. What is a forward pass?
A forward pass is the process of passing input through the network from input to output to generate a prediction. The prediction is then compared with the target using a loss function.

## 7. What is a loss function?
A loss function measures how different a prediction is from the actual target. Examples include MSE for regression and Binary/Categorical Cross-Entropy for classification. Training aims to minimize loss.

## 8. How does a neural network learn from data?
1. Input data is passed forward.
2. Loss is calculated.
3. Backpropagation computes gradients.
4. An optimizer updates weights and biases.
5. The process repeats over batches and epochs.
